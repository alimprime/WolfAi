# Phase 3 — внешние события

WolfAi хранит внешний факт как `Observation`: `event_at`, `published_at`, `ingested_at`, `source`, `source_version`, `confidence`, `value`, `unit`. В строгий backtest запись попадает только если время публикации точное, значение есть, и `published_at <= as_of`. `value = null` значит «недоступно». Измеренный ноль допустим и не используется как заполнитель пропуска.

`as_of` дневной свечи — `daily_bar_available_at`: 00:00 UTC следующих суток. Holdout с 2025-01-01 не запрашивается и не оценивается.

## Что подключено

| Источник | Как получен | Строгий backtest |
| --- | --- | --- |
| Coin Metrics Community | `https://community-api.coinmetrics.io/v4`, без ключа, лицензия Creative Commons по странице community data. Лимит 10 запросов / 6 секунд. | Нет |
| Binance Vision funding USD-M BTCUSDT | месячные ZIP и `.CHECKSUM`, с 2020-01 | Да: `published_at = calc_time` |
| Binance Vision open interest | дневные ZIP metrics, с 2020-09-01, последний снимок суток | Да: `published_at = create_time` |
| FRED graph CSV | `DFF`, `CPIAUCSL`, `VIXCLS`, последняя винтажность, без ключа API | Нет: нет vintage и часа релиза |
| NY Fed EFFR | `markets.newyorkfed.org` search JSON | Нет: в объекте нет часа публикации |

Платный корень `api.coinmetrics.io` без ключа отвечает 401 и не используется.

## Почему биржевые потоки не вошли в тест

В community-каталоге BTC есть `FlowInExNtv`, `FlowOutExNtv`, `SplyExNtv` с 2011-04-24. У этих строк `status=flash`, а `status-time` для дат до конца 2024 года лежит в апреле 2026. Документация Coin Metrics говорит, что стандартная метрика переписывает прошлое, когда позже находятся новые адреса биржи. Point-in-time ряд `FlowInExPitNtv` на пробном запросе отвечает 403.

Поэтому агрегаты сохраняются с `strict_backtest = false` и не попадают в матрицу прогноза. Приток на биржу в примечании не трактуется как продажа. Отдельных переводов между кошельками community API не отдаёт: число whale-событий считается только по категории `whale_transfer`.

`HashRate`, комиссии, эмиссия, число транзакций и активных адресов тоже сохраняются, но без исходного часа публикации. `AssetEODCompletionTime` у дат 2019 года — пакетная отметка 2021-02-26, а не утро того дня. В строгий тест они не входят. Сумма `FeeTotNtv + IssTotNtv` подписана как производная и не выдаётся за платную `RevNtv`.

## Источники, которые не вызывались

- Arkham `GET https://api.arkm.com/transfers` — кредиты, ключа нет.
- Glassnode — исторический API платный; Light API даёт 14 дней на платном Advanced.
- CryptoQuant `GET https://api.cryptoquant.com/v1/btc/exchange-flows/reserve` — on-chain не входит в бесплатный Basic.
- Farside — официального API нет, страница оставляет права за собой. HTML не скачивается. Локальный CSV принимается только с колонкой `published_at`. Даты до 2024-01-11 отвергаются: спотовые ETF США тогда не торговались, и ноль туда не пишется.
- SEC EDGAR описан, но без `User-Agent` с контактом запрос не отправляется. Заявки — не дневной поток.
- CoinGlass не вызывался: бесплатный исторический путь ликвидаций не подтверждён.
- GDELT DOC API не складывался в корпус: неполная выдача не считается известными на дату новостями. Статья без `seendate` отбрасывается.

Поздняя метка кошелька не действует до `label_published_at`. Совпадение сущности при разных адресах — внутренний перевод, он не входит в биржевой поток и не называется покупкой или продажей.

## Память и Qwen

Аналоги ищет Python, ближайшими соседями по z-оценке прошлых ситуаций. Исход 1 и 7 дней хранится отдельно и в расстояние не входит. Сосед без уже известной семидневной реакции не показывается. Если соседей меньше пяти, отчёт говорит, что аналогов недостаточно.

Qwen 3.5 4B получает короткий JSON на решение не позже 2022-12-31. В нём нет Brier и нет holdout. Инструментов, сети и счетов нет. Веса не меняются. Модель может сослаться только на даты из списка соседей. Коэффициенты считает логистическая регрессия Python. Окно 2023–2024 считается после ответа и модели не отправляется.

## Ablation

Один и тот же набор дат:

- A — только цена.
- B — цена и строгие on-chain/whale-признаки. Пока таких признаков нет, конфигурация не оценивается.
- C — цена и строгие макро/ETF-признаки. Пока таких признаков нет, конфигурация не оценивается.
- D — цена и все строгие дополнительные признаки. Сейчас это funding и суточное изменение open interest, если оба есть. Пропуски дней выбрасывают строку, а не заполняются.

Коэффициенты оцениваются на 2019–2021 внутри этой общей выборки. Главное окно — 2022. 2023–2024 считается один раз и не выбирает модель. Флаг надёжного улучшения требует, чтобы на 2022 год нижняя граница HAC была выше нуля и против ценовой логистики, и против константы 0.5, и чтобы каждый квартал с не менее чем 20 решениями показал меньший Brier. Это не формальная поправка на множественные сравнения. Диапазоны цены остаются метриками прежних baseline и внешние ряды не используют.

## Команды

```bash
python -m wolfai.intelligence acquire --directory data/intelligence --end 2024-12-31
python -m wolfai.intelligence evaluate --csv data/btcusdt_1d_2019-01_2026-09.csv --directory data/intelligence
```

Файлы в `data/` не коммитятся. Числа прогона лежат в `data/intelligence/phase3_report.json`.

## Прогон 2026-10-26

Загружено 99 948 наблюдений. Отдельных переводов крупных держателей: 0. Point-in-time поток Coin Metrics ответил 403. У `FlowInExNtv`, `FlowOutExNtv` и `SplyExNtv` время версии — апрель 2026, поэтому к решениям 2019–2024 эти строки невидимы. FRED и EFFR сохранены как описание.

Сравнение A и D идёт по 1573 общим дням, на которых есть и funding, и суточное изменение open interest. 588 более ранних ценовых дней в это сравнение не входят. Коэффициенты оценены на 425 днях примерно с октября 2020 по декабрь 2021.

Brier направления на 2022 год, 362 решения:

| Модель | Brier | Log loss |
| --- | ---: | ---: |
| Константа 0.5 | 0.25000 | — |
| Историческая частота | 0.25287 | — |
| A, только цена | 0.24970 | 0.69255 |
| D, цена + funding + изменение OI | 0.25091 | 0.69500 |

У D против A средний разрыв Brier отрицательный, интервал HAC пересекает ноль, и во всех четырёх кварталах 2022 года Brier у D выше. Флаг надёжного улучшения ложный. B и C не оценивались: строгих whale- и макро/ETF-признаков нет. Окно 2023–2024 посчитано один раз и в выбор модели не входило; там D тоже хуже A (0.24976 против 0.24879, 724 дня).

Почти все вероятности D на 2022 год лежат между 0.4 и 0.6: 361 из 362. Средняя вероятность 0.515 при доле ростов 0.451.

На 2022-12-30 Python нашёл пять прошлых соседей: 2022-12-23, 2022-10-20, 2022-10-19, 2022-01-19, 2022-01-18. Их доходности за 1 и 7 дней смотрят в разные стороны. Qwen эти даты в гипотезу не включила. Её формула использует только цену и объём; на 2022 год Brier 0.25253 при 364 днях, хуже константы 0.5. Метрики 2023–2024 модели не отправлялись.
