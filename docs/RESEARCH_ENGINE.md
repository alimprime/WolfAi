# Исследовательский движок Qwen

Qwen 3.5 4B предлагает формулу вероятности роста следующего close BTCUSDT. Python проверяет грамматику, считает метрики и пишет журнал. Веса модели не меняются. Статус `active` этот цикл не назначает.

## Подключение

Локальный адрес `http://127.0.0.1:11434/api/chat`, модель `qwen3.5:4b`. В запросе нет инструментов. Контекст ограничен 4096 токенами, ответ — 900 токенами, ожидание — 60 секунд, транспортных попыток — 3. Seed генерации — 1729. Имя модели и digest сохраняются в журнале. Если Ollama не отвечает, запуск останавливается со статусом `ollama_unavailable`.

## Формула

Корень — `sigmoid`. Внутри: признаки, числа от -10 до 10, `+ - * /`, `tanh`, `abs`, `sign`. Деление на число меньше `1e-6` по модулю даёт 0. Глубина не больше 6, узлов не больше 20. `eval` и `exec` не используются.

Признаки считаются только по свечам до бара решения включительно:

- `log_return` — лог-доходность последнего close
- `momentum_7`, `momentum_30` — изменение close за 7 и 30 дней
- `volatility_7`, `volatility_30` — стандартное отклонение лог-доходностей
- `volume_change` — изменение объёма к предыдущему дню
- `range_position` — положение close в диапазоне high/low за 30 дней

Метка — рост следующего close. Её нет среди признаков.

## Метрики

Вероятность направления оценивается Brier score и калибровкой по пяти корзинам. Рядом считаются вероятность квантильного baseline (доля уже известных ростов) и константа 0.5 у случайного блуждания. MAE и интервальный score baseline сохраняются отдельно и с Brier не сравниваются.

Знак влияния проверяется конечной разностью на обучении. Вывод о противоречии делается при не менее чем 100 наблюдениях. Иначе тип ошибки `effect_sign_inconclusive`.

## Журнал

SQLite: `data/research/hypotheses.sqlite`. Таблицы `runs` и `hypotheses`. Неудачная строка остаётся со статусом `archived`. Проверенная и не отвергнутая остаётся `experimental`.

## Holdout

Загрузчик останавливается на первой свече с датой открытия `2025-01-01` и не читает её цены. `run_research` отклоняет ряд, в котором такая свеча уже есть. Метрики holdout не считаются.

## Адаптация Phase 2.1

Qwen задаёт только структуру: признаки и преобразования `identity`, `abs`, `tanh`, `sign`. Python оценивает свободный член и веса регуляризованной логистической регрессией на 2019–2021. Признаки перед этим нормируются по истории строго раньше точки решения.

Обратная связь модели — Brier внутреннего 2022 года. Период 2023–2024 считается development-validation: он уже попадал в прошлый промпт, поэтому новые кандидаты фиксируются до этой оценки и их результаты туда не возвращаются. Holdout по-прежнему не читается.

Подробности первых пяти формул — в [диагностике](HYPOTHESIS_DIAGNOSIS.md).

## Запуск

```bash
python -m wolfai.research --csv data/btcusdt_1d_2019-01_2026-09.csv --journal data/research/hypotheses.sqlite --max-hypotheses 5
python -m wolfai.research --adaptive --csv data/btcusdt_1d_2019-01_2026-09.csv --journal data/research/hypotheses.sqlite --max-hypotheses 5
```
