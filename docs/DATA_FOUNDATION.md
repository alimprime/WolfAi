# WolfAi: этап 1 — Data Foundation

## Контракт первой версии

- **Актив:** только `BTCUSDT` Spot Binance. Его цена выражена в USDT, не в USD.
- **Разрешение:** `1d`; начало суток `00:00:00+00:00` (UTC). Свеча обозначается временем открытия.
- **Источник:** официальный публичный архив `https://data.binance.vision/` (Spot / monthly / klines / BTCUSDT / 1d).
- **Формат после импорта:** `timestamp,open,high,low,close,volume`, совместимый с текущим `wolfai.data.load_candles`.
- **Сдвиг времени:** в Spot CSV архивах Binance данные до 2025-01-01 используют миллисекунды Unix, начиная с 2025-01-01 — микросекунды. Импортёр учитывает оба варианта.
- **Качество:** положительные конечные цены, конечный неотрицательный объём, корректные OHLC, строго ежедневная непрерывность. Пропуски не заполняются вымышленными ценами.
- **Достоверность:** этот архив относится к конкретной бирже; он не описывает весь рынок BTC. Историю Bitcoin до появления соответствующих биржевых торгов необходимо добавлять из отдельно проверенного источника.

## Первый импорт — офлайн

1. Скачать выбранный архив с `https://data.binance.vision/data/spot/monthly/klines/BTCUSDT/1d/` (например, `BTCUSDT-1d-2024-12.zip`).
2. Сверить архив с опубликованным файлом `.CHECKSUM` Binance, если он доступен.
3. Из корня проекта после `python -m pip install -e '.[dev]'`:

```bash
python -m wolfai.data data/BTCUSDT-1d-2024-12.zip --output data/btcusdt_2024_12.csv
pytest
```

Файлы в `data/` не добавляются в Git благодаря `.gitignore`. Импортёр не обращается к интернету и не извлекает файлы ZIP в файловую систему. В архиве должна быть ровно одна запись, и её имя обязано совпадать с именем ZIP без расширения.

Команда импорта дополнительно проверяет календарь из имени файла: месячный архив содержит каждый день этого месяца, дневной — ровно указанные сутки. Внутренний пропуск по-прежнему отвергается. Високосный февраль учитывается. Пропуск не заполняется вымышленной ценой.

Метка `timestamp` — открытие суток UTC. Close этой свечи известен в `00:00` следующих суток (`daily_bar_available_at`). `HistoricalQuantileBaseline` ставит `as_of` на это время. Горизонт 1 или 7 дней считается от последнего известного close. Внешние ряды подключаются по `published_at` к `as_of`. Контракт полей и будущие модули описаны в [архитектуре](ARCHITECTURE.md).

## Проверенный архив декабря 2024

`BTCUSDT-1d-2024-12.zip`, SHA-256 `82ec90210f492694b9d01722f97f579108ee787968b8485b53d736ea735700da`. Официальный файл `.CHECKSUM` совпал. Внутри одна запись `BTCUSDT-1d-2024-12.csv`: 31 свеча с открытия `2024-12-01T00:00:00+00:00` по `2024-12-31T00:00:00+00:00`, шаг ровно 86 400 000 миллисекунд, повторов и пропусков нет. Время закрытия каждой свечи равно открытию плюс 86 399 999 миллисекунд, то есть 23:59:59.999 UTC. Нормализованный CSV и ZIP лежат в `data/` и в Git не входят.

Цены и объём хранятся в `float64`, как и прежний `Candle`. На этом архиве наибольшее абсолютное отличие от десятичной строки Binance меньше `10⁻¹¹`.

## Обязательные правила на будущие этапы

- Для внешних факторов (whale-события, новости, ETF, макроданные) хранить `event_time`, `published_at`, `ingested_at`, `source`, `source_version` и оценку уверенности; в прогнозе на момент `t` использовать только значения, **доступные к t**.
- Финальный тестовый период сохранять закрытым от перебора гипотез. Разделять обучение, валидацию и оценку; дальнейшую оценку проводить walk-forward.
- Отслеживать дату загрузки и checksum каждого архива. Изменения от поставщика не должны незаметно переписывать историю экспериментов.
- Поиск исторических аналогов должен работать по признакам, а не по текстовым воспоминаниям LLM; Qwen предлагает гипотезы, Python проверяет.
- Не выдавать движение между кошельками за доказанную покупку или продажу. Не подключать торговые ключи.

## История 2019–2026 и контрольные метрики

Помесячные архивы BTCUSDT Spot 1d с 2019-01 по 2026-09 проверены по SHA-256 и собраны в непрерывный ряд. Границы периодов: обучение 2019–2022, валидация 2023–2024, закрытый тест 2025-01-01 — 2026-09-30. Метрики закрытого теста не считаются. Отчёт: [контрольные прогнозы](BASELINE_2019_2024.md).
