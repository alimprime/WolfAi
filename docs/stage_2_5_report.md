## 3. Схема проверки

Прогноз можно записать только с явным `decision_time` и `target_time = decision_time + horizon`. Горизонты — 1, 3 и 7 дней. Каждый признак имеет собственное `available_at`; если оно позже решения, запись отклоняется.

Живой цикл смотрит только в канал `forward` и только при источнике `verified-local`. Такого источника нет, поэтому CLI без него отвечает `source_unavailable` и не подставляет исторический CSV. Каналы `synthetic` и `reconstruction` хранятся отдельно. Реконструкция с решением или целью в 2022 году и позже запрещена. Торговых вызовов нет, фоновый процесс не запускается.

После `target_time` исход пишется один раз. Оценка канала не переводит запись в подтверждённую гипотезу: при короткой выборке статус `insufficient_evidence`, при устойчиво худшем интервале против обоих контролей — `rejected`, и никогда `supported`.

## 4. Как хранится прогноз

SQLite, две таблицы. `predictions` только пополняется. Повтор той же модели, версии, решения, горизонта, снимка признаков и канала не создаёт вторую строку. Другая вероятность на тот же ключ отклоняется. Исправление — новая строка с `replaces_prediction_id`; чужой `model_id` такую строку вставить не может. Исход лежит в `prediction_evidence` и не заменяется другим числом.

Вероятность от 0 до 1. Рядом фиксируется baseline на момент записи, по умолчанию 0.5, чтобы сравнение не подгонялось после факта.

## 5. Утечки и происхождение

Категории: `verified`, `source_declared`, `estimated`, `unknown`.

Дневной бар получает `verified`, только если доступность — ровно следующая полночь UTC после открытия. `exchange_calc_time` и `exchange_create_time` остаются `source_declared`: это заявление файла биржи, а не доказательство, что исторический API отдавал значение в тот час. Пустая публикация — `unknown`. В строгую историческую проверку проходит только `verified`.

Четыре времени не приравниваются друг к другу. Признак с доступностью после `decision_time` в журнал не входит.

## 9. Ограничения

Настоящего forward-источника с проверенной доступностью нет, поэтому боевой прогноз BTC не создавался. `calc_time` funding по-прежнему не считается независимым доказательством исторического API. 2021 и 2022 не открывались для нового подбора. Один удачный синтетический отрезок сознательно не получает `supported`.

## 10. Готовность к арене

Есть протокол `ResearchStrategy`: идентификатор, версия и `predict` по снимку признаков. Оценка одна на всех и сидит вне стратегии. Две стратегии не могут переписать чужой прогноз. Турниров, мутаций и копий Qwen нет. Для арены позже понадобится живой источник и отдельное решение, какие каналы вообще допускаются к сравнению.
